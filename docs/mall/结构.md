# 商城结构

仓库总览和共享模块见 [结构](../结构.md)。

```text
admin/            管理后台（Vue 3 + Element Plus）
web_app/          用户端 H5（Vue 3 + Vant）
server/           商城 API
scripts/          生产一体包（含前端构建）
```

`admin` 和 `web_app` 是两个前端工程。

商城启动时打开自己的库，再交给用户模块。存储配置从商城 YAML 填进 `mediastore.Config` 后调用 `mediastore.Init`。

## server

商城业务：商品、购物车、订单、积分资产、Banner 和公告。

```text
server/
  cmd/main.go            只提供 API，默认读 configs/config.yaml
  cmd/allinone/          API，并托管 admin 与 web_app 的静态文件
  api/                   商城 proto 与生成代码
  openapi.yaml           商城接口和用户接口的 OpenAPI
  common/config          商城 YAML 配置
  common/database        本进程的 SQLite
  internal/app           组装日志、数据库、鉴权、各 HTTP 服务
  pkg/                   商品、购物车、订单、资产、展示信息
  configs/               config.yaml、config_prod.yaml
  third_party/           protoc 用的 google api、openapi 描述
```

`cmd/allinone` 默认三个端口：API `:8080`（配置里的 `server.http_addr`），管理端 `:8081`，H5 `:8082`。后两个端口把 API 路径反代到 API 进程。

商城专用错误码（库存、余额、订单状态、支付超时）在 `server/pkg/bizerror`。
