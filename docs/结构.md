# 项目结构

仓库根目录按「前端 / 商城服务 / 可复用 Go 模块」分开。

```text
mall/
  admin/            管理后台（Vue 3 + Element Plus）
  web_app/          用户端 H5（Vue 3 + Vant）
  server/           商城 API
  modules/
    kit/            日志、错误、鉴权、HTTP 响应
    user/           用户账号、登录、管理接口
    file/           本地文件上传与访问
  build.go          生成 pb、编译 Go 目标
  go.work           本地同时使用上述 Go 模块
  scripts/          生产一体包（含前端构建）
  docs/
```

`admin` 和 `web_app` 是两个前端工程。`modules` 里的包给商城用，以后的聊天服务也可以引用，不和前端放在一起。

## 模块依赖

```text
server  →  kit、user、file
user    →  kit
file    →  kit
```

模块路径是 `mall/kit`、`mall/user`、`mall/file`、`helloworld`（商城）。`go.work` 把它们列在一起，本地编译不需要再写 `replace` 才能找到源码。`server/go.mod` 里仍保留 `replace`，方便不打开工作区时单独编译商城。

数据库由每个服务自己初始化。商城的实现在 `server/common/database`。启动时把连接交给用户模块：

```text
database.InitDb(...)
userdao.SetDB(database.GetDb())
```

文件模块不读商城的配置结构。商城把 YAML 里的存储配置填进 `mediastore.Config` 再调用 `mediastore.Init`。

## modules/kit

| 包 | 作用 |
|----|------|
| `logger` | 日志 |
| `codeerror` | 通用错误类型和错误码；`error.proto` 定义 `CodeError` |
| `auth` | JWT、白名单中间件 |
| `httpx` | 统一的 `{code,msg,data}` 响应 |
| `model/common` | 软删除标记 |
| `pbjson` | Kratos JSON codec |
| `hash_balancer` | 一致性哈希选节点 |

商城专用错误码（库存、余额、订单状态、支付超时）在 `server/pkg/bizerror`。

## modules/user

账号、登录方式、注册、登录、封禁和管理员接口。

```text
modules/user/
  model/            用户表、登录方式表
  dao/              数据访问；SetDB 注入连接
  controller/       注册、登录、资料、管理端
  api/user/         用户服务 proto
  api/base/         请求里的 BaseParam
```

## modules/file

```text
modules/file/
  mediastore/       本地图片存储、逻辑 URI 和公开 URL
  mediacontroller/  上传接口和 /files/ 访问
```

## server

商城业务：商品、购物车、订单、积分资产、Banner 和公告。

```text
server/
  cmd/main.go            只提供 API，默认读 configs/config.yaml
  cmd/allinone/          API，并托管 admin 与 web_app 的静态文件
  api/                   商城 proto 与生成代码
  openapi.yaml           商城接口和用户接口的 OpenAPI
  common/config          商城 YAML 配置
  common/database        本进程的 SQLite
  internal/app           组装日志、数据库、鉴权、各 HTTP 服务
  pkg/                   商品、购物车、订单、资产、展示信息
  configs/               config.yaml、config_prod.yaml
  third_party/           protoc 用的 google api、openapi 描述
```

`cmd/allinone` 默认三个端口：API `:8080`（配置里的 `server.http_addr`），管理端 `:8081`，H5 `:8082`。后两个端口把 API 路径反代到 API 进程。
